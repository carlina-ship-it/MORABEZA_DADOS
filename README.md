# MORABEZA_DADOS
objetivo é analisar os dados de vendas da empresa fictícia Morabeza Distribuição, utilizando Python, para calcular a faturação total, a faturação por ilha e identificar a ilha com maior volume de vendas.
# Objetivos
•	Ler e importar dados de vendas a partir de um ficheiro CSV.
•	Calcular o valor total de cada venda.
•	Calcular a faturação total.
•	Agrupar a faturação por ilha.
•	Identificar a ilha com maior faturação.
•	Calcular a faturação mensal.
•	Formatar valores monetários em CVE.

# Tecnologias Utilizadas
•	Python
•	CSV
•	Pytest
•	Git e GitHub
•	GitHub Codespaces
